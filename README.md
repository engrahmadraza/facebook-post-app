# Facebook Post App

A Facebook-style post sharing interface built with vanilla JavaScript and Bootstrap 5. Users can create posts with a title, description, and multiple images, then edit, delete, and comment on them.

## Features

- Create posts with a title, description, and image uploads
- Facebook-style image layouts for 1, 2, 3, and 4+ images
- Edit and delete posts from a dropdown menu
- Add timestamped comments to any post
- View all images of a post in a modal gallery

## Tech Stack

- HTML5
- CSS3
- JavaScript (DOM manipulation, Blob URLs)
- Bootstrap 5.3.8 (CDN)
- Font Awesome 6.5.1 (CDN)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/engrahmadraza/facebook-post-app.git
   ```
2. Open the folder in VS Code.
3. Run it with the Live Server extension, or open `index.html` in a browser.

> **Note:** Posts are stored in memory only. Refreshing the page clears all posts.
